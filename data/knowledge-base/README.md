# Knowledge base (SAMPLE)

These articles are **sample help-centre content** for an imaginary retailer, "Lumora Electronics",
written for this learning project. They are not real policies of any company.

- One article per ticket subject in `data/raw/customer_support_tickets.csv` (16 subjects).
- Format: Markdown with a small front-matter block (`title`, `subject`, `sample`).
- Ingest them with `pnpm ingest`. This README is skipped by ingestion.
- Replace them with real help-centre articles at any time; re-run `pnpm ingest`.
