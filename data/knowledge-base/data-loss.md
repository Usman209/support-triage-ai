# Recover lost photos, files or settings

Stop using the device or memory card as soon as you notice data is missing. New data can overwrite
files that are still recoverable.

## Check your backups first

- **Lumora Cloud**: open the Lumora app, go to **Backups** and restore the latest backup. Backups
  are kept for **30 days**.
- **Deleted items**: many devices and apps keep deleted photos in a "Recently deleted" folder for
  **30 days**.
- **Computer**: check the folder you used for imports or sync.

## Memory cards (cameras, action cameras, drones)

1. Remove the card and do not format it, even if the device asks you to.
2. Put it in a computer card reader and copy any files you can see.
3. Use a reputable photo-recovery tool on a copy of the card, not the original.

## After a firmware update or reset

A factory reset removes all data on the device. If data disappeared after a firmware update
without a reset, restart the device twice and check again: some devices rebuild their file index
after an update.

## What support can and can't do

Lumora support can help restore cloud backups and check for device faults. We cannot recover data
from a damaged memory card or storage chip. If the data is critical, use a professional
data-recovery service before sending the device for repair: **repairs may erase all data**.
