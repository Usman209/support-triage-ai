Step 03

Observability: Langfuse

Record every AI request (prompt, answer, tokens, cost, time, errors) so we can debug and measure. We use Langfuse Cloud; a self-hosted stack is ready but switched off.

Cloud: 2 keys, no maintenance. Self-hosted: 6 containers, your data stays local. Start it with pnpm infra:up:langfuse-local.

Problems and fixes

SymptomLocal Langfuse asked for a username/password
CauseSelf-hosted starts with no users
FixSign up locally, or use Cloud (chosen)
Lesson: self-hosted tools often start empty.
SymptomWorker logged "table does not exist"
CauseWorker started before the database migrations finished
FixNone needed: stopped after 15 s
Lesson: check timestamps before panicking about startup errors.
Symptom6 unused containers running
CauseWe moved to Langfuse Cloud
FixCompose profile, off by default
Lesson: don't run what you don't use; keep it easy to turn back on.
Interview line: "LLM apps are non-deterministic, so we trace every request: inputs, outputs, tokens, cost, latency and scores. Cloud or self-hosted depends on data rules; either way we redact PII before anything leaves our system."
