Problems and fixes

SymptomPorts 3000 and 3001 already in use
CauseOther local containers (Metabase, another backend)
FixWEB_PORT=3010, API_PORT=3011
Lesson: check ports first; always make them configurable.
SymptomNext.js ignores WEB_PORT
CauseNext reads only PORT or --port
FixLauncher script passes the port from config
Lesson: bridge tools to your config instead of hardcoding.
SymptomFirst page load took ~13 s
CauseDev mode compiles each page on first request
FixNothing; fast afterwards and in production
Lesson: dev speed is not production speed.
Interview line: "We built a walking skeleton first: browser to web to API with a health endpoint. Features are added to a system that already runs end to end."
