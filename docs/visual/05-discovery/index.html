Discovery brief

Who it is for, what hurts, how we measure success, and what the AI may and may not do. Decided before building any AI feature.

3. Approval rules

Action Rule Why
Search help centre, read ticket, similar tickets No approval Read-only
Set category / priority Approval Wrong value misroutes the ticket
Draft reply Approval Customer-facing text
Internal note, escalate / assign Approval Moves work between people
Send to customer, close, refund, delete Never by AI High impact or irreversible

4. Top risks and their guards

Hallucination

Answer only from retrieved articles, show citations, groundedness evals.

Wrong action

Human approval for every write, audit log.

PII leak

Redact before the LLM and before tracing.

Prompt injection

Injection checks, tool allow-list, approval gate.

Cost overrun

Daily budget guard, cheap-model routing.

Automation bias

Citations, confidence, track edits and rejects.
