LLM providers: chat + embeddings

3. Which errors to retry

Error Meaning Retry?
429 rate limit Too many requests right now Yes, with backoff
5xx / timeout / network Temporary server or network problem Yes, with backoff
429 insufficient_quota No credit (billing) No
400 Bad request (e.g. temperature on Claude 5.x, low credit) No
401 / 403 Bad key / no permission No

Backoff in voyage.ts: 0.5 s → 1 s → 2 s, up to LLM_MAX_RETRIES.

4. Query vs document embeddings

flowchart LR
  q["User question
'I forgot my password'"] -->|"embed(..., inputType: 'query')"| qv(("query vector"))
  d1["'How do I reset my password?'"] -->|"inputType: 'document'"| dv1(("doc vector"))
  d2["'I want a refund'"] -->|"inputType: 'document'"| dv2(("doc vector"))
  qv -. "high similarity" .-> dv1
  qv -. "low similarity" .-> dv2

Voyage adds a retrieval hint per type, so short questions land close to the passages that answer them. Run pnpm ai:smoke to see the numbers.

5. Claude settings that changed (API drift)

No temperature

Current Claude models reject it (400). Only open models get LLM_TEMPERATURE.

Effort

LLM_EFFORT low → max: how much the model thinks. Quality vs cost and latency.

Thinking uses tokens

LLM_MAX_OUTPUT_TOKENS 1024 → 4096 so answers aren't cut off.

Refusal fallback

fallbacks: 'default': a safety-declined request is retried on another model.
