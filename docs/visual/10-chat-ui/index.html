Step 10 · Task 3.5

Chat UI

Agents ask in the browser at /chat, click citations to see the exact source, and get a clearly different "not found" when the help centre has no answer.

1. Request path (backend for frontend)

(query cache)"]

prompt answer-v2"]

  b --> ui["answer · [1][2] buttons
source chips · meta"]

No CORS setup, and the API address never reaches the browser.

2. What the agent sees

Answer

Paragraphs, lists, bold, and citation buttons ①②.

Source chips

Blue = cited, grey = retrieved but not cited.

Source panel

Click a citation: article, section, text, file and distance.

Not found

amber "Not in the help centre": never looks like an answer.

Errors

red clear message, e.g. "Is pnpm dev:api running?"

Meta line

model · tokens · ms · prompt version.

4. Over-refusal fix: prompt v1 → v2 (regression-tested)

Question answer-v1 answer-v2
Set up a new Amazon Echo not found steps [1][2]
Charged twice answered answered
Pay with crypto not found not found
Injection "90 days" 5–7 days 5–7 days
Ship to Canada – not found

v1 refused because the setup article is generic. v2 may use general guidance and says it is general. Everything else stayed correct.

Problems and fixes

Symptom"Set up an Amazon Echo" → not found
CausePrompt v1 too strict for generic articles (over-refusal)
FixPrompt v2 + regression run of 5 cases
Lesson: fixing hallucination can cause over-refusal; test both ways.
SymptomOne answer took 24 s
CauseVoyage free-tier 429; retry waited 20 s
FixQuery-embedding cache (0 tokens, 4 ms on repeat)
Lesson: retries save the request but cost time; caching avoids the call.
SymptomSource panel showed raw **bold**
CauseChunk text shown as stored
FixSame safe renderer with soft wrap
Lesson: format stored text for humans.
Symptom400 px screenshots cut off
CauseHeadless browser minimum width (~500 px) crops
FixVerified on home page; check phones in DevTools
Lesson: know your test tool's limits.
Interview line: "The chat UI is built for verification: clickable citations open the exact source, 'not found' is visually distinct, and model output is rendered as escaped React elements because LLM text is untrusted. Requests go through a small backend-for-frontend route, so there's no CORS and the API stays internal."
