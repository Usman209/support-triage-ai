Lesson: decide which system owns each field.
Interview line: "We load tickets with an allow-list of columns, so personal data never enters the database, redact contact details from free text, fill the dataset's template placeholders, and upsert on the ticket id so loads are repeatable without overwriting fields owned by approved agent actions. A check script verifies all of it."
