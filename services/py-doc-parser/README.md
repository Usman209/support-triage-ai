# py-doc-parser (task P2, placeholder)

Python service that uses **Docling** to turn help-centre documents (PDF, DOCX, HTML) from
`data/knowledge-base/` into clean, structured text for RAG ingestion.

Status: placeholder only (this README and `pyproject.toml`).

Planned setup:

```bash
cd services/py-doc-parser
python -m venv .venv
# activate it, then: pip install -e .
```

Settings come from the root `.env`. Nothing is hardcoded.
